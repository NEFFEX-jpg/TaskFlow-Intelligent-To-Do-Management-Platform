# 周报生成技能

当用户输入 `/weekly-report` 时，生成本周开发周报。

## 执行步骤

1. **获取本周日期范围**
   - 计算本周一到本周日的日期（YYYY-MM-DD 格式）
   - 如果今天是周末，生成上一个完整工作周的周报

2. **收集 Git 提交记录**
   - 运行 `git log --since="本周一日期" --until="本周日后日期+1" --oneline --all` 获取本周所有提交
   - 运行 `git log --since="本周一日期" --until="本周日后日期+1" --stat --all` 获取文件变更详情
   - 统计提交数量、修改文件数、新增/删除行数

3. **收集代码变更摘要**
   - 运行 `git diff --stat` 查看未提交的改动
   - 运行 `git status` 查看工作区状态

4. **收集待办事项**
   - 读取 `src/App.tsx` 中 localStorage 的 todos 数据逻辑
   - 询问用户是否有未完成的重要任务需要列入周报

5. **生成周报**

## 周报格式

```
# 开发周报

**汇报人**：[询问用户姓名]
**周期**：YYYY/MM/DD - YYYY/MM/DD

---

## 一、本周完成

按日期或功能模块列出已完成的工作：
- [功能/任务名称]
  - 完成内容概述
  - 关键提交 hash（可选）

## 二、开发详情

### 代码统计
- 提交次数：X 次
- 新增文件：X 个
- 修改文件：X 个
- 代码变更：+XXX / -XXX 行

### 主要变更
- [文件/模块]：[变更说明]
- ...

## 三、技术难点与解决方案
- [遇到的问题及解决方式，如无可写"无"]

## 四、下周计划

- [ ] [待办事项 1]
- [ ] [待办事项 2]
- [ ] [其他计划]

## 五、待办事项

列出当前项目中未完成的 todo 项：
- [任务名称] [重要标记：重要/一般]

---

**备注**：[可选补充说明]
```

## 输出方式

- 先将周报生成到当前目录下的 `weekly-report-YYYY-MM-DD.md` 文件
- 然后在对话中展示周报内容
- 询问用户是否需要修改或调整
